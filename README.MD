# 🪙 Веб-приложение «Конвертер валют» (Интеграция с API ЦБ РФ)

Современное full-stack веб-приложение для конвертации валют, реализованное в виде **монорепозитория**. Система интегрирована напрямую с **официальным XML API Банка России (ЦБ РФ)**, кэширует данные в структурированном хранилище MongoDB с помощью автоматического планировщика задач (cron) и мгновенно визуализирует расчеты на клиенте благодаря реактивным **Angular Signals**.

Проект разработан в качестве демонстрационного элемента портфолио (публичный кейс для резюме) и отражает лучшие практики создания Full-Stack систем: детерминированное управление состоянием, фоновое выполнение долгоживущих задач, устойчивость к сбоям внешних API и модульная архитектура.

---

## 🚀 Ключевые особенности

*   **Прямая официальная интеграция:** Стабильный пайплайн работы с официальным шлюзом ежедневных курсов `cbr.ru` без посредников.
*   **Слой потокового декодирования:** Корректное преобразование кодировки `windows-1251` в `utf-8` на уровне буферов Node.js. Это исключает обрывы сетевых пакетов и защищает XML-парсер от частой ошибки `CDATA is not closed`.
*   **Архитектура на базе БД:** Фронтенд-клиент (Angular) делает запросы исключительно к `MongoDB`, что обеспечивает молниеносный отклик API (< 15 мс) и снимает нагрузку с серверов Центробанка.
*   **Автоматизация через Node-Cron:** Планировщик задач жестко синхронизирован с московским временем (`Europe/Moscow`) и автоматически обновляет базу данных свежими курсами ежедневно ровно в **18:15 МСК**.
*   **Реактивность на Angular Signals:** Архитектура состояния фронтенда построена на современных сигналах (`signal` и `computed`), обеспечивая точечное (fine-grained) обновление DOM-дерева без лишних циклов проверки зон (`Zone.js`).
*   **Синхронизированный UI на Template-driven Forms:** Использование модулей Angular-форм предотвращает рассинхрон между выбранным элементом в динамическом выпадающем списке `<select>` и внутренним состоянием приложения.

## 🛠 Технологический стек

### Бэкенд (Backend)
*   **Платформа:** Node.js (v20+, синтаксис ES Modules)
*   **Фреймворк:** Express.js
*   **Работа с БД:** Mongoose (MongoDB ODM)
*   **Библиотеки и парсеры:** Axios, Fast-XML-Parser, Iconv-lite
*   **Планировщик:** Node-Cron

### Фронтенд (Frontend)
*   **Фреймворк:** Angular 16+ (Standalone-компоненты, TypeScript)
*   **Управление состоянием:** Angular Signals (`signal`, `computed`)
*   **Формы и интерфейс:** Template-driven Forms (`FormsModule`), адаптивная нативная верстка на CSS Grid / Flexbox (без использования тяжелых UI-библиотек).

## ⚙️ Установка и локальный запуск

### 1. Настройка бэкенда (`/backend`)
Перейдите в папку бэкенда, установите зависимости и настройте переменные окружения.

```bash
cd backend
npm install
```

Создайте файл `.env` или укажите системные переменные окружения. Для локального запуска:
```env
MONGO_URI=mongodb://localhost:27017/currency_converter_db
PORT=3000
```

Запустите сервер:
```bash
node server.js
```

### 2. Настройка фронтенда (`/frontend`)
Перейдите в папку фронтенда, установите зависимости и запустите локальный сервер разработки Angular.

```bash
cd ../frontend
npm install
ng serve
```
Откройте браузер по адресу `http://localhost:4200` для работы с приложением.

### 🌐 Облачное развертывание (Готов к Amvera Cloud)
В корне репозитория подготовлен готовый конфигурационный манифест `amvera.yml`. Проект полностью оптимизирован для быстрого деплоя в облако Amvera с поддержкой постоянных дисковых хранилищ (persistent volumes) и внутренних сетевых линков между контейнером Node.js и MongoDB.
