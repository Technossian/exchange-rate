# ⚙️ Бэкенд-модуль (Express.js + MongoDB + Node-Cron)

Серверная часть приложения «Конвертер валют». Отвечает за сбор данных с официального шлюза ЦБ РФ, их фильтрацию, кэширование в СУБД MongoDB по расписанию и логирование пользовательских запросов.

## 🚀 Архитектурные решения и фичи

*   **Надежный сетевой транспорт (Анти-Блокировка):** 

    Центробанк часто обрывает соединения автоматических скриптов на Node.js, что вызывает ошибку парсинга XML `CDATA is not closed`. Данный сервис полностью маскирует запросы под реальный браузер (с поддержкой `keep-alive`, кастомных заголовков `User-Agent` и `Host`), гарантируя 100% загрузку данных.

  
* **Стриминговое декодирование (windows-1251 -> utf-8):** 

  Поскольку ЦБ РФ отдает данные в старой кодировке, бэкенд преобразует массив бинарных байт на низком уровне через библиотеку `iconv-lite` перед передачей в XML-парсер.
  

* **Автоматизация через Node-Cron (Europe/Moscow):** 

    Крон-задача автоматически просыпается каждый день в **18:15 по Московскому времени** (когда ЦБ публикует официальный курс на следующий день), скачивает свежие данные, фильтрует только нужные валюты (`USD`, `EUR`, `GBP`, `BYN`, `GEL`, `AED`, `TRY`, `AMD`) и обновляет документы в MongoDB методом `upsert` (без дублирования записей).
  

* **Логирование истории:** 
    
  Каждый запрос от клиента с параметром `?target=CODE` автоматически фиксируется в коллекции `histories` для формирования ленты последних 10 запросов.

## 🛠 Спецификация REST API

### 1. Получение курсов и истории
*   **URL:** `/api/v1/rates`
*   **Метод:** `GET`
*   **Query-параметры:** `target` (опционально, например `/api/v1/rates?target=USD`) — код валюты для записи в историю.
*   **Пример успешного ответа (JSON):**
```json
{
  "success": true,
  "rates": [
    {
      "code": "USD",
      "name": "Доллар США",
      "nominal": 1,
      "value": 92.45,
      "updatedAt": "2026-10-05T15:00:00.000Z"
    }
  ],
  "history": [
    {
      "fromCurrency": "RUB",
      "toCurrency": "USD",
      "timestamp": "2026-10-05T15:30:22.123Z"
    }
  ]
}
```

## 🛠 Запуск в режиме разработки

1. Установите зависимости:
   ```bash
   npm install
   ```
2. Настройте локальную СУБД MongoDB.
3. Запустите сервер:
   ```bash
   node server.js
   ```
