# 🔴 Клиентская часть приложения «Конвертер валют».
Представляет собой современный, быстрый SPA-интерфейс, спроектированный по принципу "воздушного" минимализма (Clean UX).

## ⚙ Функционал

  - ввод суммы в одной валюте;
  - выбор целевой валюты из выпадающего списка;
  - отображение результата конвертации;
  обновление курсов через API cbr.ru;
  - история последних операций (В разработке).

## 🚀 Ключевые особенности и технологии

*   **Angular Signals & Computed Properties:** 

    Вся реактивная логика и пересчет сумм завязаны на новые Сигналы Angular (доступны в Angular 16+). Использование `computed()` позволяет автоматически вычислять итоговую сумму конвертации «на лету» без тяжелых RxJS-цепочек и подписок.


*   **Fine-grained Rendering (Точечный рендеринг):** 
    
    Благодаря архитектуре сигналов, при вводе цифр в инпут обновляется исключительно текстовый узел итогового значения. Это избавляет приложение от лишней работы Zone.js и тотальных проверок изменений (Change Detection).


* **Template-driven Forms (`FormsModule`):** 

    Двустороннее связывание данных `[(ngModel)]` синхронизировано с Сигналами через геттеры и сеттеры в классе компонента. Это предотвращает классический баг рассинхронизации динамического выпадающего списка `<select>` при первичной загрузке массива асинхронных данных.

  
* **Адаптивная Native CSS верстка:**

    Интерфейс построен на чистом CSS (Grid Layout + Flexbox) без использования сторонних тяжелых CSS-библиотек (Bootstrap, Angular Material). Обеспечивает идеальное отображение на смартфонах, планшетах и десктопах.

## 📂 Структура управления состоянием (State Management)

*   `rate.service.ts` — отвечает исключительно за сетевые HTTP-запросы к Express-бэкенду.
*   `store.service.ts` — глобальное реактивное хранилище состояния приложения. Содержит сигналы для списка валют (`rates`), индикатора загрузки (`loading`), ошибок (`error`), введенных рублей (`rubAmount`), выбранного кода (`selectedCurrencyCode`) и логов истории (`history`).

## 🛠 Запуск в режиме разработки

1. Установите Angular CLI глобально (если не установлен):
   ```bash
   npm install -g @angular/cli
   ```
2. Установите локальные зависимости:
   ```bash
   npm install
   ```
3. Запустите сервер разработки (по умолчанию откроется на `http://localhost:4200`):
   ```bash
   ng serve
   ```
